Three Ways to Add CSS

1. External CSS

The styles for this page's body, headings and cards come from css/external-style.css. It is attached in the head using:

<link rel="stylesheet" href="css/external-style.css">

This is the best method for a real website, because one file can style every page and a single edit updates all of them.

2. Internal CSS

The dashed border and light blue background of this box are written inside a <style> block in the head of this page. It applies only here, which suits a one-off page or a quick test.

3. Inline CSS

This sentence is styled with a style attribute written directly on the tag.

Inline CSS has the highest priority but cannot be reused, so keep it for small exceptions only.

Which one wins?

  • Inline style beats internal and external
  • Whichever of internal or external comes later in the head wins
  • A more specific selector beats a general one, whatever the method
