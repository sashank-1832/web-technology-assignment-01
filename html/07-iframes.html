Inline Frames (iframe)

An <iframe> shows one web page inside another page. The old <frameset> tag was removed in HTML5, so iframe is the correct way to do this today.

4. Useful iframe attributes

  • src — the page to display
  • width / height — size of the frame in pixels
  • name — lets a link with target="name" load into it
  • title — describes the frame for screen readers
  • loading="lazy" — loads only when scrolled into view
