3. Common attributes

  • controls — shows the player controls
  • autoplay — starts playing automatically (most browsers allow it only when muted)
  • loop — repeats from the start when it ends
  • muted — starts with the sound turned off
  • poster — image shown before the video plays (video only)
  • preload — hint to the browser: none, metadata or auto
