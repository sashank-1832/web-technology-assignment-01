About HTML

HTML stands for HyperText Markup Language. It is the standard markup language used to create the structure of web pages. A browser reads the HTML and shows the content on the screen.

A paragraph is written using the p tag. The browser automatically adds space above and below every paragraph, so two paragraphs never stick together.
