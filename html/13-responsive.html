What is it

One page that adjusts itself to the size of the screen, instead of building a separate site for mobile. The same HTML is reused and only the CSS changes.

How it works

Widths are set in percentages or with flexible layouts rather than fixed pixels, images are limited with max-width: 100%, and media queries change the rules at chosen widths.

Writing a media query

@media screen and (max-width: 600px) { ... } applies the rules inside it only when the screen is 600 pixels wide or narrower.

Breakpoints used on this page

  • 901px and above — three cards in a row, horizontal menu
  • up to 900px — two cards per row
  • up to 600px — one card per row, menu stacks vertically
  • print — menu and footer are removed

The <meta name="viewport"> tag in the head is what tells a phone to use its real width. Without it, media queries appear to do nothing on a mobile device.
